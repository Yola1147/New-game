# Проверяемые этапы

## Фактическое состояние — 14.11.2026, #20

База приёмки #20: `fe0578b`, main после PR #43; #19 и задачи #6–#7 закрыты.
Прототип включает последовательный маршрут станции, два героя, два варианта
стража, головоломку, Эхо, один предмет и локальное сохранение. Это реализация
механик, а не завершённая приёмка версий. Канон не расширен.

### Выполнено в прототипе

- [x] M0–M1: структура Godot, канон, лицензия, движение, камера, прыжок и коллизии; пользовательская оценка предыдущей сборки без замечаний.
- [x] M2 / #1–#2: один враг, преследование вокруг препятствий, атака, урон, смерть и повтор боя; исправлен щелчок захвата курсора.
- [x] M3 / #3–#5: два простых героя, независимые HP/откаты, Q, метка и сильный удар; регрессии и общее пользовательское подтверждение.
- [x] M4 / #6–#7: последовательный диалог, поручение, журнал и однократная награда.
- [x] M5 / #8–#11: компактная станция, проходимый маршрут, механизм E/Q/E, нейтральная запись Эха; сверка текстов с каноном и пользовательское подтверждение маршрута.
- [x] M6 / #12–#14: усиленный вариант стража, финал технического пролога, учебный клинок, сохранение/загрузка и новая игра; автоматические проверки.
- [x] #15: пользовательский замер **40 секунд** до конца записи; исправлена индикация причин отказа G, после этого пользователь подтвердил работоспособность.
- [x] #16: локальный Windows x64 архив, лицензии и метаданные, проверки ресурсов и отдельного запуска exe; пользователь подтвердил восстановление выполненного задания после перезапуска.
- [x] #17: актуальные инструкции запуска и управления, ограничения, разделение результатов и фактический roadmap; результаты повторных проверок — PLAYTEST.md.
- [x] #18 / v0.2.0: приёмка базового боя #1–#2, версия проекта, повторные проверки и prerelease исходников. Ручная оценка перенесена из #2 с исходными ограничениями. Приёмка завершена.
- [x] #19 / v0.3.0: приёмка двух персонажей и взаимодействия #3–#5, версия проекта, повторные проверки и prerelease исходников. Ручная оценка перенесена из #5 с исходными ограничениями. Приёмка завершена.
- [x] #20 / v0.4.0: приёмка диалога и одного квеста #6–#7, версия проекта, повторные проверки и prerelease исходников. Ручная оценка историческая из #11 / #15 с исходными ограничениями. Следующая цель — v0.5.0 / #21.

- [ ] Отдельный ручной F9 в самостоятельном exe и подробный протокол пользовательских действий; сейчас F9 подтверждён автоматически.
- [ ] Приёмки #21–#23 и соответствующие выпуски по VERSIONING.md.
- [ ] M7 как принятый вертикальный срез для Windows / v0.7.0.

в текущую документационную задачу. Новые дизайнерские решения здесь не приняты.

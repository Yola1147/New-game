# Проверяемые этапы

- [x] M0: структура Godot, канон, правила разработки, лицензия MIT.
- [x] M1a: персонаж, камера, WASD, прыжок, коллизии и арена; импорт и запуск без ошибок; автоматическая проверка движения (выполнено).
- [ ] M1b: ручная оценка управления и камеры у стен.
- [ ] M2: один враг — обнаружение, преследование, атака, здоровье, получение урона, смерть, перезапуск. Проверить полный бой и отсутствие урона после смерти.
- [ ] M3: два простых персонажа, переключение без восстановления здоровья/кулдаунов, разные роли и одно взаимодействие способностей. Затем расширение до четырёх.
- [ ] M4: диалог с последовательностью реплик, журнал одного квеста, корректные переходы задач без повторной награды.
- [ ] M5: руины станции, бои, одна головоломка и прототип «Эха памяти». Сюжетная проверка отсутствия спойлеров.
- [ ] M6: усиленный противник, завершённый пролог, минимальная прогрессия/экипировка и сохранение. Проверить загрузку и сброс.
- [ ] M7: замер прохождения 10–15 минут, исправление блокеров, Windows-сборка и проверка запуска вне редактора.

Следующая итерация после приёмки основы: M2. Подробности дальнейшего мира определять после работающего пролога.

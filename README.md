# New game

Одиночная оригинальная 3D Action RPG на **Godot 4.x и GDScript**. Текущее состояние исходников — игровой прототип: закрытая арена, камера от третьего лица, два переключаемых героя, один враг и взаимодействие двух способностей. Графика, роли и числовой баланс временные и не определяют канон игры.

Это ещё не вертикальный срез на 10–15 минут. Есть прототип последовательного диалога с выдачей поручения; журнал и переходы квеста, сюжетное прохождение, сохранения, прогрессия, четыре полноценных персонажа и открытый мир пока не реализованы.

## Запуск

Проверенное окружение: **Windows, Godot 4.7.2 stable, Compatibility / OpenGL**. Внешних ассетов и дополнительных зависимостей проекта нет.

Откройте `project.godot` в Godot 4.x и нажмите **F5** для запуска проекта. Рекомендуется проверенная версия движка.

На этом компьютере также доступен запуск из PowerShell в папке проекта:

```powershell
# Игра
powershell -ExecutionPolicy Bypass -File .\Run.ps1

# Редактор
powershell -ExecutionPolicy Bypass -File .\Run.ps1 -Editor

# Автоматические проверки
powershell -ExecutionPolicy Bypass -File .\Run.ps1 -Test
```

`Run.ps1` ищет консольный исполняемый файл Godot в `.tools/godot` и использует локальный профиль `.tools/profile`. Папка `.tools` не входит в Git: на другом компьютере установите Godot отдельно и откройте проект в редакторе либо разместите portable-версию с `*console.exe` в `.tools/godot`.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD | Движение относительно камеры |
| Мышь | Поворот камеры при захваченном курсоре |
| Пробел | Прыжок |
| ЛКМ | Обычная ближняя атака |
| Q | Переключение между двумя героями |
| E | Способность активного героя при захваченном курсоре |
| Esc | Захват / освобождение курсора |
| R | Полный перезапуск боя |
| F | Открыть / повторить диалог с поручением |
| Enter / кнопка «Далее» | Следующая реплика; после последней — принять поручение |

Первый щелчок ЛКМ при свободном курсоре только захватывает его; следующий запускает удар. При падении ниже арены персонаж возвращается автоматически.

## Диалог и поручение (прототип #6)

Живой активный герой может нажать **F** в любой точке тестовой арены. Три реплики по порядку предлагают команде исследовать заброшенную станцию рядом с поселением и предупреждают о монстрах в руинах. **Enter** или кнопка переводит к следующей реплике; автоповтор клавиши отключён. На последней реплике кнопка **«Принять поручение»** подтверждает выдачу, и HUD показывает поручение. **Esc** выходит без принятия; следующий разговор начинается с первой реплики.

Во время диалога бой, движение, камера и таймеры приостановлены. Курсор освобождается и после выхода возвращается в прежний режим; кнопки разговора не вызывают удар, способность, смену героя или перезапуск. Начатые до разговора удары продолжаются после выхода. Повторное завершение не выдаёт поручение заново, R перезапускает только бой и сохраняет принятое поручение до закрытия игры.

Это прототип интерфейса без NPC, станции, журнала, награды и сохранения на диск. Журнал и переходы задач относятся к #7. Авторские секреты и новые законы мира в репликах отсутствуют.

## Бой и команда

Красный страж стоит на противоположной стороне арены и преследует подошедшего героя, обходя стены и колонны. Перед ударом он становится оранжевым на **0,65 секунды** — за это время можно выйти из зоны атаки. Навигация рассчитана на статическую арену на уровне пола; подъём на платформы и динамические препятствия не поддерживаются.

У каждого героя и стража по **100 HP**. Обычная атака героя наносит **25 урона**, удар стража — **20**. У атаки есть задержка попадания и восстановление; один удар наносит урон один раз. Герой бьёт в направлении своего взгляда, поворот камеры не меняет направление начатого удара. Стены блокируют попадания.

**Q** переключает бирюзового героя №1 и фиолетового героя №2. У них общие положение, скорость, направление и камера, но независимые HP, восстановление атак и защита после получения урона. Таймеры продолжают идти в резерве; переключение не лечит и не сбрасывает восстановление. Незавершённое попадание при смене героя отменяется. Резерв не получает урон.

Погибшего героя выбрать нельзя. После гибели активного нажмите Q для перехода к живому резервному. Поражение наступает после гибели обоих, победа — после гибели стража. **R** восстанавливает всю команду и врага, выбирает героя №1, очищает таймеры, эффекты и незавершённые удары. HUD показывает здоровье команды и стража, готовность способностей и итог боя.

## Способности и взаимодействие

| Герой | Способность по E | Эффект |
| --- | --- | --- |
| №1, бирюзовый | Метка | Попадание перед собой до 6 м; на 5 секунд замедляет стража с 2,8 до 1,4 м/с. Метка видна как бирюзовое кольцо. |
| №2, фиолетовый | Сильный удар | Ближний сектор до 2,4 м; 35 урона или 60 по действующей метке с её расходованием. |

Чтобы выполнить связку: **E героя №1 → Q → приблизиться → E героя №2**, пока не истекли пять секунд метки. Обычная атака метку не расходует; HUD сообщает о сработавшем взаимодействии.

У каждой способности независимое восстановление **6 секунд**, включая промах. Таймеры идут в резерве и сохраняются при Q. Способность недоступна погибшему герою и во время восстановления обычной атаки. Направление, расстояние, высота и стены ограничивают попадание. Это технический прототип ролей, а не утверждённые законы магии.

## Проверки

Результаты предыдущих проверок от **13.11.2026** описаны в [PLAYTEST.md](PLAYTEST.md): импорт Godot 4.7.2, шесть автоматических наборов, запуск основной сцены в headless и с графическим рендерером завершились без ошибок. Графические прогоны использовали OpenGL 3.3 / NVIDIA GeForce RTX 4060 Ti.

`Run.ps1 -Test` запускает наборы последовательно и останавливается при ненулевом коде завершения:

| Набор | Что проверяет |
| --- | --- |
| `tests/smoke.gd` | Движение, прыжок, коллизии и возврат после падения |
| `tests/combat.gd` | Попадания, направление атак, урон, смерть, перезапуск и ввод ЛКМ |
| `tests/navigation.gd` | Обход препятствий, недостижимую цель и возобновление преследования |
| `tests/party.gd` | Переключение, независимые HP и таймеры, смерть команды |
| `tests/abilities.gd` | Способности, метку, усиленный удар и их ограничения |
| `tests/team_combat.gd` | Интеграцию способностей и переключения, восстановление в резерве, отмену отложенных попаданий и сброс боя |
| `tests/dialogue.gd` | Порядок реплик, отмену/повтор, однократную выдачу поручения, блокировку ввода, паузу боя и таймеров; с графикой — курсор и завершающий щелчок по кнопке |

Проверка #6 от **13.11.2026**: импорт, все семь headless-наборов и headless-запуск основной сцены — без ошибок; `dialogue.gd` с OpenGL — 0 ошибок. Ассистент визуально осмотрел HUD арены и снимок окна первой реплики 1280×720. Проверка клавиш через desktop-инструмент не подтверждена из-за потери доступного окна; ручное прохождение пользователем не проводилось. Это не заменяет ручную приёмку. Подробности — [PLAYTEST.md](PLAYTEST.md).

Headless не поддерживает захват мыши: соответствующие ветки ввода проверялись отдельно автоматическими прогонами с графикой. Автоматический графический запуск не равнозначен ручному прохождению. Пользователь сообщил «не заметил ошибок» после проверки базового боя и «вроде все работает» после передачи сценариев командного боя; подробного протокола действий и отдельной оценки баланса нет. Ассистент визуально осмотрел стартовый HUD, полного ручного прохождения не заявлял.

Эти проверки не подтверждают Windows-экспорт или длительность прохождения. Имеющаяся локальная Windows-сборка не пересобиралась в рамках проверки командного боя; для текущих исходников используйте запуск через Godot.

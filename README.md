# New game

Одиночная оригинальная 3D Action RPG на **Godot 4.x и GDScript**. Текущее состояние исходников — игровой прототип: компактные руины станции, камера от третьего лица, два переключаемых героя, один тип врага в обычном и усиленном вариантах и взаимодействие двух способностей. Графика, роли и числовой баланс временные и не определяют канон игры.

Это ещё не вертикальный срез на 10–15 минут. Есть прототип последовательного диалога с выдачей поручения, журнал одного квеста и нейтральная запись Эха памяти; технический маршрут пролога доведён до завершения в #12. В #13 добавлен один предмет за поручение, в #14 — сохранение у входа и загрузка. Полноценная прокачка, четыре полноценных персонажа и открытый мир пока не реализованы.

## Запуск

Проверенное окружение: **Windows, Godot 4.7.2 stable, Compatibility / OpenGL**. Внешних ассетов и дополнительных зависимостей проекта нет.

Откройте `project.godot` в Godot 4.x и нажмите **F5** для запуска проекта. Рекомендуется проверенная версия движка.

Локальный Windows x64 прототип после #15: **`build/windows/New game.exe`** — двойной щелчок, Godot устанавливать не нужно. Ресурсы встроены в `.exe`; отдельного `.pck` нет. При передаче сборки сохраните рядом `LICENSE` и `GODOT_COPYRIGHT.txt`. Свежая сборка подготовлена в #16; результаты проверок перечислены в PLAYTEST.md. Это прототип, не выпуск новой версии. Для выхода закройте окно или нажмите Alt+F4.

Повторная сборка на этом компьютере:

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

`Build.ps1` сначала импортирует проект, затем делает release-экспорт по `export_presets.cfg`. Требуются portable Godot 4.7.2 в `.tools/godot` и Windows x64 export templates той же версии в `.tools/godot/editor_data/export_templates/4.7.2.stable`. Официальные шаблоны уже установлены локально. `build/` исключён из Git; исходники и настройки сборки сохраняются в репозитории. После изменений игры запускайте сборку заново.

Для передачи используется `build/New-game-windows-x64.zip`: exe со встроенными
ресурсами, `LICENSE`, `GODOT_COPYRIGHT.txt` и `build-info.json` (ревизия, признак
изменённых исходников, версия движка, время UTC и SHA-256 exe). Распакуйте архив
целиком и запустите `New game.exe`; редактор и исходники рядом не нужны.
Обычный exe сохраняет в `%APPDATA%/Godot/app_userdata/New game/prologue.json`;
профиль запуска через `Run.ps1` отдельный, поэтому его слот в exe не переносится.

Воспроизводимая автоматическая проверка сборки:

```powershell
powershell -ExecutionPolicy Bypass -File .\Verify-WindowsBuild.ps1
powershell -ExecutionPolicy Bypass -File .\Verify-WindowsBuild.ps1 -Graphics
```

Проверка сверяет SHA-256, выполняет 15 регрессий на встроенном в exe PCK
через соответствующую версию движка, отдельно проверяет сохранение/загрузку
в двух процессах и запускает сам release-exe из другой рабочей папки.
Официальный шаблон 4.7.2 запрещает `--script`, поэтому эти два вида запуска
разделены. Тестовые скрипты остаются снаружи архива; временные копии и логи —
`build/validation`, профиль — `.tools/export-profile`. `-Graphics` использует
OpenGL и сохраняет снимки маршрута. Это автоматическая проверка; ручное
прохождение записывается отдельно в `PLAYTEST.md`.

В PowerShell из папки проекта:

```powershell
# Игра
powershell -ExecutionPolicy Bypass -File .\Run.ps1

# Редактор
powershell -ExecutionPolicy Bypass -File .\Run.ps1 -Editor

# Автоматические проверки
powershell -ExecutionPolicy Bypass -File .\Run.ps1 -Test
```

`Run.ps1` ищет консольный исполняемый файл Godot в `.tools/godot` и использует локальный профиль `.tools/profile`. Папка `.tools` не входит в Git: на другом компьютере установите Godot отдельно и откройте проект в редакторе либо разместите portable-версию с `*console.exe` в `.tools/godot`.

## Управление

| Ввод | Действие |
| --- | --- |
| WASD | Движение относительно камеры |
| Мышь | Поворот камеры при захваченном курсоре |
| Пробел | Прыжок |
| ЛКМ | Обычная ближняя атака |
| Q | Переключение между двумя героями |
| I | Надеть / снять наградной учебный клинок команды |
| E | Способность активного героя при захваченном курсоре |
| Esc | Захват / освобождение курсора |
| R | Перезапуск только боя с сохранением квеста и головоломки |
| T | Новая игра: сброс всего прогресса и удаление сохранения |
| F5 / F9 в окне игры | Сохранить у входа / загрузить слот |
| G | Найти Эхо памяти / повторить запись рядом с ним после поручения и победы |
| F | Открыть / повторить диалог с поручением |
| Enter / кнопка «Далее» | Следующая реплика; после последней — принять поручение |

Первый щелчок ЛКМ при свободном курсоре только захватывает его; следующий запускает удар. При падении ниже арены персонаж возвращается автоматически.

Для сохранения встаньте в жёлтый круг у стартового входа, вне боя и атаки.
Доступность F5 указана внизу; результат операции остаётся в панели справа
вверху: зелёное «Сохранено» либо жёлтое «НЕ СОХРАНЕНО» с причиной.
Нажмите Esc, чтобы воспользоваться кнопками «Сохранить» и «Загрузить» в этой
панели. После успешного сохранения повторный запуск exe автоматически
восстанавливает прогресс и возвращает команду ко входу.

## Диалог и поручение (прототип #6)

Живой активный герой может нажать **F** в любой точке тестовой арены. Три реплики по порядку предлагают команде исследовать заброшенную станцию рядом с поселением и предупреждают о монстрах в руинах. **Enter** или кнопка переводит к следующей реплике; автоповтор клавиши отключён. На последней реплике кнопка **«Принять поручение»** подтверждает выдачу, и HUD показывает поручение. **Esc** выходит без принятия; следующий разговор начинается с первой реплики.

Во время диалога бой, движение, камера и таймеры приостановлены. Курсор освобождается и после выхода возвращается в прежний режим; кнопки разговора не вызывают удар, способность, смену героя или перезапуск. Начатые до разговора удары продолжаются после выхода. Повторное завершение не выдаёт поручение заново, R перезапускает только бой и сохраняет принятое поручение до закрытия игры.

Это прототип интерфейса без NPC; временные руины добавлены в #8, сохранение — в #14. Журнал и переходы задач реализованы в #7, см. ниже. Авторские секреты и новые законы мира в репликах отсутствуют.

## Журнал одного квеста (прототип #7)

Журнал постоянно виден в нижней части экрана. Состояния: нет поручения → победить стража → открыть проход → победить усиленного стража → найти Эхо памяти → выполнено. Примите поручение через F и три подтверждения Enter, победите обычного стража, откройте механизм связкой E/Q/E, победите усиленного стража в дальней комнате, затем подойдите к бирюзовой площадке и нажмите **G** в пределах 2,5 м. Осмотр требует живого активного героя, обеих побед и открытого механизма. Убийство до принятия поручения засчитывается после принятия, чтобы не блокировать прохождение; ранний осмотр не запоминается.

Завершение однократно увеличивает видимый счётчик тестовой награды до 1 и выдаёт учебный клинок (прототип #13, см. ниже). Повторные G, диалог и R не дублируют награду. Валюты и новых сюжетных сведений нет; предмет и площадка используют временную геометрию. После R требуется снова победить обоих стражей; открытый механизм сохраняется. Журнал незавершённого поручения возвращается к цели боя в зале.

**R** сбрасывает только бой и сохраняет принятый/завершённый квест. **T** начинает новую игру: восстанавливает бой, убирает поручение, возвращает диалог к непринятому состоянию, обнуляет награду и удаляет слот. Повторный запуск автоматически загружает сохранение, если оно корректно. Во время диалога G и T заблокированы.

## Минимальная прогрессия и экипировка (прототип #13)

Находка Эха после завершения поручения однократно выдаёт и автоматически надевает **учебный клинок команды**. **I** снимает / надевает полученный предмет для обоих героев. Обычный удар: **25 без клинка, 30 с клинком (+5)**; сильный удар остаётся 35, связка с меткой — 60. Бонус вычисляется от базового значения и не накапливается. Состояние предмета и итоговые числа постоянно видны над журналом. До награды I ничего не делает; автоповтор, диалог и гибель активного героя блокируют смену экипировки. Бонус определяется при попадании обычного удара.

R сохраняет предмет и выбор экипировки, T удаляет предмет и возвращает урон к 25. После T поручение снова может выдать один клинок. Новый запуск восстанавливает предмет и выбор из слота #14. Это временный баланс без уровней, инвентарной сетки, валюты и новых сведений канона; предмет пока представлен записью в HUD.

`tests/equipment.gd` включён в `Run.ps1 -Test`: выдача, повторы, реальный урон обоих героев, способности, ограничения ввода и R/T. Импорт, 14 headless-наборов, графическая регрессия экипировки и запуск основной сцены пройдены; снимки HUD осмотрены. Ручное прохождение #13 и пересборка Windows-exe не проводились; подробности — PLAYTEST.md.

## Сохранение, загрузка и новая игра (прототип #14)

Один ручной слот: **F5 в окне игры** сохраняет у входа станции (радиус 3 м от точки X=0, Z=8). Нужен живой активный герой вне обычного удара; живые стражи должны быть дальше 11,5 м. При преследовании сначала завершите бой либо нажмите R. **F9** загружает в любой точке вне диалога; запуск автоматически продолжает корректный слот. Автосохранения при выходе нет. Сообщение внизу экрана показывает результат операции.

Сохраняются HP обоих героев (включая погибшего), активный герой, квест, однократная награда, владение и выбор клинка, открытие двери и победы над обоими стражами. Загрузка возвращает ко входу; живые враги возвращаются домой с полным HP. Кулдауны, замахи, метки, движение и воспроизведение записи сбрасываются. Незавершённый журнал сверяется с восстановленным маршрутом; награда повторно не выдаётся.

**T** сразу удаляет слот и начинает новую игру. R меняет только текущую попытку, записанный слот не обновляет. При ошибке удаления новая игра отменяется с сообщением. Отсутствующий, повреждённый, несовместимый или противоречивый JSON не применяется: при запуске остаётся новая игра, при F9 — текущее состояние. Запись идёт через временный файл с заменой после успешной записи.

Файл: `user://prologue.json`; при Run.ps1 — `.tools/profile/Godot/app_userdata/New game/prologue.json`, при обычном Godot — `%APPDATA%/Godot/app_userdata/New game/prologue.json`. Регрессии используют отдельный `regression-issue14.json` и не загружают игровой слот. `tests/save_load.gd` включён в Run.ps1 -Test; для проверки между процессами запускайте его сначала с `-- --write`, затем с `-- --read`. Это технический прототип без изменения канона.

Проверка #14: импорт, 15 headless-наборов, запись/автозагрузка в двух процессах, графический save_load и основная сцена (headless 120 / OpenGL 180 кадров) пройдены. Снимок интерфейса осмотрен; ручное прохождение и Windows-экспорт не выполнялись. Подробности — PLAYTEST.md.

## Руины станции и маршрут (прототип #8)

Одна замкнутая локация 32×32 м из встроенных примитивов Godot: входной портал → зал с одним обычным стражем → закрытый центральный проход → обозначенный обход справа → бирюзовая площадка места находки. Светлые полосы на полу и таблички показывают путь; он проходится без прыжков и позволяет вернуться ко входу. Стартовая позиция безопасна от обнаружения. Страж обходит опоры и закрытый проход через боковой проём; R/T возвращают его в зал, героя — ко входу.

Центральный проход открывает механизм из #9, обход доступен сразу. С #12 обход позволяет исследовать дальнюю комнату, но не заменяет обязательное решение механизма и усиленный бой. В #10 на площадке добавлен предмет «Эхо памяти» с нейтральной текстовой записью; G завершает находку и запускает воспроизведение. Все формы, материалы и указатели временные, помечены как прототип. Открытого мира, нового типа врага и новых сведений канона не добавлено.

Регрессия `tests/station.gd` включена в `Run.ps1 -Test`: обычное движение по всему пути и обратно, коллизия закрытого прохода, обход стражем, бой четырьмя базовыми ударами, блокировку раннего осмотра через обход и сброс. Для графического запуска и снимков входа, прохода и находки: Godot `--path . --script tests/station.gd -- --capture` (PNG в игнорируемой `.tools/`). Автоматическое прохождение и осмотр снимков не заменяют ручную проверку; подробности — PLAYTEST.md.

## Локальная головоломка (прототип #9)

Слева перед центральной дверью стоит временный механизм с подписью. Подойдите к нему, смотрите на него и примените **E героя 1 с расстояния до 6 м → Q → E героя 2 с расстояния до 2,4 м** в течение пяти секунд. Используются существующие способности, их направления, ограничения высоты, проверка стен и независимые откаты по 6 с. Обычная атака механизм не активирует. Подсказка рядом с дверью показывает порядок, текущую метку и открытие; цвет механизма также меняется.

Неверный порядок и истёкшая метка не портят механизм: дождитесь восстановления и повторите связку. Открытый проход остаётся открытым при повторных активациях и **R**; герой и страж могут пройти через него в обе стороны. **T** сбрасывает дверь, метку, бой и квест, возвращая героя ко входу. Диалог приостанавливает таймер метки. Боковой обход сохранён и доступен сразу: с #12 механизм обязателен для появления усиленного стража и находки по G.

Это технический прототип взаимодействия, без новых законов магии и сюжетных откровений. В новой игре дверь закрыта; #14 восстанавливает её из сохранения. `tests/puzzle.gd` включён в `Run.ps1 -Test`; для графической проверки со снимками: Godot `--path . --fixed-fps 60 --script tests/puzzle.gd -- --capture`. Результаты и ограничения — [PLAYTEST.md](PLAYTEST.md).

## Эхо памяти (прототип #10)

После принятия поручения, открытия прохода и победы над обоими стражами подойдите к светлому предмету на бирюзовой площадке дальней комнаты и нажмите **G** в пределах 2,5 м. Находка однократно завершает квест и выдаёт тестовый результат. Справа автоматически воспроизводятся три нейтральные текстовые реплики неизвестных исследователей, по 4 секунды каждая. Это текстовый прототип без озвучки; связи исследователей с героем запись не раскрывает.

Движение, камера, бой и переключение доступны во время записи; курсор сохраняет свой режим. Повторное G во время записи не перезапускает её. После окончания G рядом с предметом повторяет запись без новой награды, пока оба стража побеждены. F останавливает запись перед разговором, R останавливает её с сохранением находки, T очищает весь прогресс попытки. Запись исчезает автоматически; сохранения на диск нет.

`tests/memory_echo.gd` добавлен в `Run.ps1 -Test`: условия находки, порядок и завершение реплик, движение, повторы, журнал и R/T; с графикой дополнительно события Q/E и снимки через `-- --capture`. Проверки #10: импорт и все 11 headless-наборов с `--fixed-fps 60`, графическая регрессия и запуск основной сцены — без ошибок. Визуально осмотрены снимки первой/последней реплик и завершения при 1280×720. Ручного прохождения и пересборки Windows-экспорта не было; подробности — [PLAYTEST.md](PLAYTEST.md).

## Усиленный страж и финал (прототип #12)

Маршрут: поручение → обычный страж в зале → механизм E/Q/E → усиленный страж в дальней комнате → G у Эха → завершение поручения и запись. Усиленный страж появляется только после первой победы и открытия механизма, один раз за бой. Если механизм решён раньше боя или обе победы одержаны до принятия поручения, прогресс учитывается после принятия. Обход доступен, раннее G не выдаёт находку.

Это вариант существующего AI: **175 HP, 30 урона**, фиолетовый корпус с широкой плечевой перекладиной, постоянная подпись и отдельная строка HP в HUD. Оранжевый замах **0,65 с**, восстановление **1 с**, дальность и скорость прежние; метка, замедление и связка 60 урона действуют как раньше. Босса и новых законов магии нет, числа и внешний вид временные.

Поражение не выдаёт находку. **R** восстанавливает обоих героев и обычного стража у входа/в зале, удаляет усиленного до следующей победы в зале; открытая дверь, поручение и уже выданная награда сохраняются. **T** также закрывает проход и очищает поручение/находку. После завершения повторная запись требует нового прохождения боёв при R, второй награды нет. Сохранения и прогрессия относятся к #13–#14.

`tests/prologue.gd` проверяет порядок, усиленный AI, гибель команды, R/T, уклонение по замаху, способности и однократную находку. Обновлённый `tests/station_playthrough.gd` проходит оба боя с живым AI и весь маршрут без телепортаций героя. Все 13 наборов в `Run.ps1 -Test` используют фиксированный шаг 60 FPS. Графический маршрут и снимки: Godot `--path . --fixed-fps 60 --script tests/station_playthrough.gd -- --capture`; результаты — [PLAYTEST.md](PLAYTEST.md), ручной сценарий — [STATION_REVIEW.md](STATION_REVIEW.md). Windows-exe этой итерацией не пересобирался.

## Бой и команда

Красный страж стоит в зале станции и преследует подошедшего героя, обходя стены и колонны. Перед ударом он становится оранжевым на **0,65 секунды** — за это время можно выйти из зоны атаки. Навигация рассчитана на статическую арену на уровне пола; подъём на платформы и произвольные динамические препятствия не поддерживаются. Открытие/сброс двери головоломки перестраивает сетку навигации.

У каждого героя и обычного стража по **100 HP**; у усиленного — **175 HP**. Обычная атака героя наносит **25 урона**, удар обычного стража — **20**, усиленного — **30**. У атаки есть задержка попадания и восстановление; один удар наносит урон один раз. Герой бьёт в направлении своего взгляда, поворот камеры не меняет направление начатого удара. Стены блокируют попадания.

**Q** переключает бирюзового героя №1 и фиолетового героя №2. У них общие положение, скорость, направление и камера, но независимые HP, восстановление атак и защита после получения урона. Таймеры продолжают идти в резерве; переключение не лечит и не сбрасывает восстановление. Незавершённое попадание при смене героя отменяется. Резерв не получает урон.

Погибшего героя выбрать нельзя. После гибели активного нажмите Q для перехода к живому резервному. Поражение наступает после гибели обоих, победа в зале — после гибели обычного стража, доступ к находке — после победы над усиленным. **R** восстанавливает всю команду и обычного стража, удаляет усиленного до следующей победы в зале, выбирает героя №1, очищает таймеры, эффекты и незавершённые удары. HUD показывает здоровье команды и стража, готовность способностей и итог боя.

## Способности и взаимодействие

| Герой | Способность по E | Эффект |
| --- | --- | --- |
| №1, бирюзовый | Метка | Попадание перед собой до 6 м; на 5 секунд замедляет стража с 2,8 до 1,4 м/с. Метка видна как бирюзовое кольцо. |
| №2, фиолетовый | Сильный удар | Ближний сектор до 2,4 м; 35 урона или 60 по действующей метке с её расходованием. |

Чтобы выполнить связку: **E героя №1 → Q → приблизиться → E героя №2**, пока не истекли пять секунд метки. Обычная атака метку не расходует; HUD сообщает о сработавшем взаимодействии.

У каждой способности независимое восстановление **6 секунд**, включая промах. Таймеры идут в резерве и сохраняются при Q. Способность недоступна погибшему герою и во время восстановления обычной атаки. Направление, расстояние, высота и стены ограничивают попадание. Это технический прототип ролей, а не утверждённые законы магии.

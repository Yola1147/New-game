# New game

Одиночная оригинальная 3D Action RPG. Сейчас реализована первая техническая итерация: персонаж, камера от третьего лица, движение, прыжок, закрытая арена, платформы и коллизии. Это ещё не вертикальный срез на 10–15 минут.

## Запуск на этом компьютере

В PowerShell из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Run.ps1
powershell -ExecutionPolicy Bypass -File .\Run.ps1 -Editor
powershell -ExecutionPolicy Bypass -File .\Run.ps1 -Test
```

Либо открыть project.godot в Godot 4.x и нажать F6/F5. Проверенная версия: Godot 4.7.2 stable, Compatibility/OpenGL. Portable Godot и MinGit скачаны из официальных GitHub releases в .tools; эта папка не входит в Git. На другом компьютере требуется отдельно установить Godot 4.x (рекомендуется проверенная версия). Внешних ассетов и зависимостей проекта нет.

Управление: WASD — движение относительно камеры, мышь — камера, пробел — прыжок, Esc — захват/освобождение курсора, щелчок — захват, R — возврат на старт. При падении ниже арены персонаж возвращается автоматически.
